# Test data

- `wordpiece_golden.tsv`: one case per line, `text TAB ids`. Text escapes: `\\`, `\t`, `\n`, `\r`.
  The ids are what the Hugging Face `tokenizers` library produces from the model's `tokenizer.json`
  (all-MiniLM-L6-v2, truncation 64, special tokens added). Generated by `gen_golden.py` in
  `/workspace/scratch/semantic-spike` (`venv/bin/python gen_golden.py <worktree>`), which needs the
  model's `tokenizer.json` and the `tokenizers` package. Special-token strings such as "[SEP]" and words that mix ASCII with non-ASCII symbols are left out, because
  the simplified tokenizer in `src/wordpiece.cpp` is documented to differ there. Non-ASCII cases are limited to ones where
  the simplified tokenizer in `src/wordpiece.cpp` is documented to agree (single symbols and CJK
  characters, no accents).
- `embedding_golden.tsv`: `text TAB 384 floats`, unit-length embeddings from onnxruntime-Python with
  `model_quint8_avx2.onnx`, for the embedder parity test.
